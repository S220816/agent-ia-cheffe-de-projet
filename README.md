# agent-ia-cheffe-de-projet
Un agent IA de gestion de projet qui analyse le planning, les fichiers CSV et les échanges avec les fournisseurs pour repérer les jalons menacés par un retard. Il explique l’impact sur les échéances, cite ses sources et prépare un point d’avancement avec des actions proposées. La décision finale revient au responsable du projet.
